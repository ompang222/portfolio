# 2026-27 UEFA 챔피언스리그 — 경기별 승률과 우승 확률

> 개인 분석 · Python · NumPy · SciPy · 포아송 모델 · 몬테카를로 시뮬레이션
> 경기 결과·부상 소식에 맞춰 시즌 중 계속 갱신합니다

### ▶ [대시보드 열기](https://ompang222.github.io/portfolio/06_ucl-2026-27/)

우승 확률 · 경기마다 이길 확률과 예상 스코어(한국 시간 킥오프) · 리그 페이즈 예상 순위 · 반영 중인 결장 명단을 한 페이지에서 봅니다.

## 방법

1. **팀 전력** — Opta 파워 레이팅(전 세계 클럽 0~100점, 매일 갱신)
2. **결장자 반영** — 부상·징계 기사를 확인해 그 경기 날짜에 한해 팀 레이팅을 낮춤 (출전 불투명은 절반)
3. **경기 예측** — 레이팅 차이 → 양 팀 기대 득점 → 포아송 분포로 스코어별 확률.
   계수는 Opta가 공개한 2차전 경기별 승률 26개에 맞춤 (평균 오차 7.9%p)
4. **시즌 시뮬레이션** — 남은 리그 경기 + 녹아웃 플레이오프 · 16강 · 8강 · 4강(홈 앤드 어웨이, 연장·승부차기) + 단판 결승을 3만 번.
   시뮬레이션마다 팀 레이팅을 ±1.5점 흔들어 시즌 중 전력 변화를 반영
5. **진행 중인 경기** — 현재 스코어에서 남은 시간만 시뮬레이션
6. **경기별 외부 요인** — 경기 카드에 요인마다 홈 승 확률을 몇 %p 바꿨는지 표시
   - **팀별 홈 이점**: 자국 리그 11,908경기로 팀마다 홈·원정 차이를 쟀지만, 시즌 간 상관이 **r = 0.015**로 거의 우연이었습니다 → 재현성만큼(1% 안팎)만 반영 (`home_advantage.py`, `out/home_adv_check.txt`)
   - **중립 경기장**: 자국에서 홈경기를 못 치르는 샤흐타르는 홈 이점 0
   - **상대전적**: 최근 맞대결 5경기에서 기대보다 얼마나 잘했나 — 표본이 작아 최대 20%만, 3년 지나면 절반
   - **이동 거리 · 휴식일 · 날씨(킥오프 시각 예보)**: 효과가 작은 요인이라 작은 가정값

## 실시간 갱신

- **페이지**: 경기 시작 20분 전부터 브라우저가 30초마다 ESPN 스코어를 직접 읽어 스코어·경기 시간·골·퇴장과 그 경기 승률을 바로 고칩니다
- **GitHub Actions** (`.github/workflows/ucl-update.yml`): 경기 중 10분마다 결과 반영·우승 확률 재계산, 평소 6시간마다 레이팅·상대전적·날씨까지 전체 갱신
- **부상 정보**는 기사를 읽고 사람이 `data/injuries.csv`를 고칩니다

**검증**: 2차전 직전 Opta 슈퍼컴퓨터의 우승 확률(아스널 21% · 맨시티 18% · 바이에른 17% · 바르셀로나 9%)과 순서가 같고 수치도 비슷합니다.

## 한계

- 올 시즌 실제 결과만으로 계수를 추정하면 강팀이 더 유리하게 나옵니다(0.13 vs 0.09). 아직 표본이 작아 참고만 합니다
- 결장 영향 점수는 기사를 보고 정한 가정값입니다
- 토너먼트 대진의 같은 시드 쌍 안 추첨은 무작위로 처리했습니다
